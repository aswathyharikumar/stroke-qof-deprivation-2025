# Stroke QOF Deprivation Study 2025

Analysis examining the association between socioeconomic 
deprivation and stroke/TIA care quality in English general 
practices using 2024-25 QOF data.

## Data Sources
- QOF 2024-25 (NHS Digital)
- Index of Multiple Deprivation 2025 (MHCLG)
- GP Practice List Sizes April 2025 (NHS Digital)

## Files
- 01_data_cleaning.R — data linkage and processing
- 02_analysis.R — statistical analysis
- cleaned_stroke_dataset.csv — final cleaned dataset
- results_summary.txt — full analysis results
- boxplots_by_quintile.png — box plots by IMD quintile
